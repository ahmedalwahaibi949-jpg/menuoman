# Awesome DESIGN.md

Each folder in `design-md/<site>/` holds a `DESIGN.md` (tokens, colors, type, spacing, component rules) and a `README.md`.

1. List `design-md/` and pick the site(s) matching the user's request.
2. Read that `DESIGN.md` fully before writing UI.
3. Use it as the design reference (or copy it to the project root as `DESIGN.md` if the user wants it persisted). Take the design language as inspiration; do not copy logos, brand names or trademarked assets.
