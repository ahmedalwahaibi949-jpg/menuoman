# menuoman

Static landing page for Ahmed's interactive QR menu design business (Oman). No build step: open `index.html`.

- `index.html`: the main site (dark food theme, configurator, plans, FAQ). Generated by `tools/site.py` — edit the generator, then run `python tools/site.py` (needs `pip install qrcode` only for older versions).
- `nana/index.html`: old N'ana Tea showroom (current client). Videos in `videos/`.
- `assets/`: fonts.css (embedded fonts) and food cutouts from N'ana Tea.
